# 🌐 3D Public API Explorer

A visually stunning, interactive 3D website built with React, Three.js, and Framer Motion. This project integrates multiple public APIs into a unified, responsive interface with scroll-based animations and educational content.

## 🚀 Live Demo
**[View the Live Site](https://abhinavsingh-hub.github.io/3d-api-explorer/)**

## ✨ Features
- **3D Background**: Interactive starfield and floating geometry using `@react-three/fiber` and `@react-three/drei`.
- **Scroll Animations**: Dynamic entrance animations for cards using `framer-motion`.
- **API Integrations**:
  - **Dog Finder**: Random dog images with breed parsing.
  - **Joke Generator**: Daily dose of humor with setup and punchlines.
  - **User Profile**: Random user data with detailed contact info.
  - **JSON Explorer**: Interactive data lists from JSONPlaceholder.
- **API Education**: A dedicated page teaching users about API concepts and integration.
- **Premium Design**: Glassmorphism, custom typography, and responsive layouts.

## 🛠️ Tech Stack
- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS v4
- **3D Engine**: Three.js (React Three Fiber)
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavsingh-hub/3d-api-explorer.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
